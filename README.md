# 🔍 Следователь СК — Интерактивный квест

Интерактивная браузерная игра, в которой вы выступаете в роли следователя Следственного комитета. Вам предстоит раскрыть дело о разбойном нападении, принимая процессуальные решения на основе **Уголовного кодекса (УК РФ)** и **Уголовно-процессуального кодекса (УПК РФ)**.

Игра создана для проверки и закрепления знаний по уголовному праву и процессу в игровой форме. Все вопросы основаны на реальных статьях кодексов, предоставленных в открытом доступе.

## 🎮 Демо
