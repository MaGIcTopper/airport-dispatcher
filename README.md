# ATC PRO — Airport Tower

Расширенная браузерная игра-диспетчер аэропорта. Работает без библиотек и сборки.

## Что добавлено
- Схема аэропорта с ВПП, терминалом, радарными окружностями и самолётами.
- Выбор бортов на радаре и в панели рейсов.
- Команды: заход на посадку, зона ожидания, взлёт со стоянки, уход на второй круг.
- Погода: ясно, дождь, туман.
- Сложность, топливо, эшелоны, конфликт траекторий и журнал диспетчера.
- Адаптация под телефон и компьютер.

Это аркадная игра, а не реальный тренажёр управления воздушным движением.
